Design pattern — Supervisor (orchestrator)

          
This is a supervisor (orchestrator) multi-agent pattern. The Director is the supervisor — it holds the goal, calls the CRM tool for data, delegates writing and reviewing to specialist agents that each run on their own runtime, then executes the approved code in a sandbox. Specialists don't talk to each other — everything routes through the supervisor, which keeps control, retries, and tenant isolation in one place.
